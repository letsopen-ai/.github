# letsopen-ai

**Tinyware, openly built.**

1. **Openly Rebuilt** — Every tool worth using is worth rebuilding in the open, with code you can read, fork, audit, and keep, and with respect for your existing workflows.
2. **Tinyware, Not Bloatware** — Small, focused, native apps do their job completely and get out of the way.
3. **Local-First, Private by Design** — We design for storage on your devices, minimal cloud services, minimal data collection, and encryption wherever your content travels.
4. **Verify, Don't Trust** — Code, builds, and data paths should be verifiable, with trust required only where strictly necessary.

## Public

- [TinyStats](https://github.com/letsopen-ai/tinystats) — All your Mac's stats in a tiny footprint.
- [tinyAgentAccess](https://github.com/letsopen-ai/tinyagentaccess) — A local-first Rust MCP server for AI agents, with no AWS dependency.

## In development

- **tinyPass** — A tiny, local-first password manager built for existing workflows.
- **Teleframe** — Native remote access to your Mac, with a relay available to carry the connection.
