# letsopen-ai

**Tinyware, openly rebuilt.**

1. **Openly Rebuilt** — Every tool worth using is worth rebuilding in the open: code you can read, fork, audit, and keep, with respect for your existing workflows.
2. **Tinyware, Not Bloatware** — Everything you need, and nothing more: small, focused, native apps that do their job completely, then get out of the way.
3. **Local-First, Private by Design** — We design for storage on your devices, minimal cloud services, minimal data collection, and encryption wherever your content travels.
4. **Verify, Don't Trust** — Code, builds, and data paths should be verifiable, with trust required only where strictly necessary.

**tinypass:** A tiny, local-first password manager built for existing workflows.

**tinystats:** All your Mac's stats. Tiny footprint.

**teleframe:** Native remote access to your Mac; a relay may carry the connection.
